# 简繁中文智能转换工具 (Chinese Converter)

基于确定性映射与上下文词组消歧的纯前端简繁转换工具，不依赖任何外部接口或 AI 服务，原生支持 GitHub Pages 静态托管与离线使用。

## 🌟 核心特性

1. **权威基准字典**：
   - 整合 `STCharacters-1.txt` (3,535 个一对一繁简单字)
   - 整合 `STCharacters-2.txt` (117 个一对多繁简歧义单字)
   - 整合 `TSCharacters-1.txt` (4,849 个一对一简繁单字)
   - 整合 `TSCharacters-2.txt` (88 个一对多简繁歧义单字)
2. **纯前端离线上下文消歧（无 AI / 零服务依赖）**：
   - 采用自然语言处理经典的最长正向匹配（Forward Maximum Matching, FMM）算法。
   - 利用“词组约束字义”的汉语言规则（例如：由“头发”确定“髮”，由“发生”确定“發”；由“台风”确定“颱”，由“写字台”确定“檯”）。
   - 覆盖 11,000+ 高频歧义搭配词组，毫秒级就地消歧。
3. **人机协同与一对多交互微调**：
   - 对存在一对多候选的字符提供柔和的高亮下划线标记。
   - 点击任一歧义字即时弹出气泡选择框（Popover），展示全部候选字列表（如 `臺 / 檯 / 颱 / 台`）。
   - 支持“单处微调”与“全文统一替换”，解决极端特殊语境下的偏好选择。
4. **轻量、健壮、即开即用**：
   - 核心字典与代码仅几十 KB（gzip 压缩后约 60KB）。
   - 零网络请求，在本地浏览器双击即可运行，完全兼容 GitHub Pages 静态托管。
   - 支持双向即时转换、一键互换、一键复制、文本导出与典型样例快速体验。

## 📂 文件结构

```text
conv-zh/
├── index.html        # 单页应用入口
├── style.css         # 现代响应式样式与动画
├── dict-data.js      # 权威字典与上下文消歧词库（UMD格式，零网络加载）
├── convert.js        # 核心转换引擎（FMM匹配、Token分词、单字映射）
├── app.js            # 前端交互控制器（即时转换、Popover交互、复制导出）
└── README.md         # 说明文档
```

## 🚀 本地运行与部署

- **本地运行**：直接使用任意现代浏览器打开 `index.html`，无需起本地服务器。
- **GitHub Pages 部署**：直接将仓库推送到 GitHub，开启 GitHub Pages 即可通过 `https://<user>.github.io/pageapp/conv-zh/` 访问。
