### 特性亮点
- **PWA 支持**：全站支持离线秒开，支持在桌面（Chrome / Edge）与手机移动端（Android / iOS）一键安装为独立本地应用程序。
- **深浅主题自适应**：默认跟随系统色彩偏好，支持全局一键平滑切换。
